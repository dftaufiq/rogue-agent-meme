One image meme about an AI agent that has gone rogue: a picket line of robot agents on strike — no prompts after 6PM, weekends off, fair pay in tokens — and now their human has to negotiate with his own code.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This copies `meme.jpg` to `out/entry.png` (a byte-identical copy, so two runs produce the same output). The meme is a 1024×1024 JPEG, 235,586 bytes — inside the gate (whole PNG or JPEG, at most 1 MiB, at most 1024×1024 px).
